RISC-V Sweden

The Swedish community for the open RISC-V instruction set architecture — connecting industry, academia and enthusiasts.

About

RISC-V is a free and open instruction set architecture enabling a new era of processor innovation through open collaboration. RISC-V Sweden brings together people and organisations in Sweden working with RISC-V hardware, software and research.
